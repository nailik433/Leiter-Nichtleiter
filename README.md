# Leiter und Nichtleiter

Interaktive Animation für den Physikunterricht: Warum leiten Metalle und Graphit den Strom, Kunststoff, Holz, Glas und Luft aber nicht?

**Live:** https://nailik433.github.io/Leiter-Nichtleiter/

Oben steckt eine Materialprobe im Stromkreis, unten zeigt eine Lupe das Innere der Probe:
- **Metalle (Kupfer, Aluminium):** Freie Elektronen wandern gemeinsam vom Minuspol zum Pluspol, das Lämpchen leuchtet.
- **Graphit:** Weniger freie Elektronen, das Lämpchen leuchtet schwach.
- **Kupferlackdraht:** Leitet erst, wenn der Lack an den Enden abgeschmirgelt ist.
- **Kunststoff, Holz, Glas, Luft:** Alle Elektronen sitzen fest im Atom, es fließt kein Strom.

Extras: Versuchsprotokoll, das sich beim Testen automatisch füllt, „Ein Elektron verfolgen“, Vollbild für den Beamer, Klick auf den Schalter direkt in der Zeichnung.

Tastatur: `Leertaste` Schalter · `1`–`8` Material · `T` Elektron verfolgen · `P` Anhalten · `F` Vollbild

Direktlinks auf einen Zustand, z. B. `?material=glas&schalter=zu` (Materialien: `kupfer`, `alu`, `graphit`, `lack`, `kunststoff`, `holz`, `glas`, `luft`).

Eine einzelne HTML-Datei ohne Abhängigkeiten (nur Google Fonts). Läuft auch offline im Browser.
